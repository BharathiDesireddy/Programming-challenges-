# problem no : 54
# Problem : [spiral matrix](https://leetcode.com/problems/spiral-matrix/description/)
# Description : 
** Given an m x n matrix, return all elements of the matrix in spiral order.

Example 1:

Input: matrix = [[1,2,3],[4,5,6],[7,8,9]]
Output: [1,2,3,6,9,8,7,4,5]

### Java Solution : 
```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
      int top=0,bottom=matrix.length-1;
      int left=0,right=matrix[0].length-1;  
      List<Integer> list = new ArrayList<>();
      while(left<=right && top<=bottom){
        //traversing left to right
        for(int i=left;i<=right;i++){
            list.add(matrix[top][i]);
        }
        top++;
        //traversing top to bottom;
        for(int i=top;i<=bottom;i++){
            list.add(matrix[i][right]);
        }
        right--;
        //traversing right to left if top and bottom are not equal
        if(top<=bottom){
            for(int i=right;i>=left;--i){
                list.add(matrix[bottom][i]);
            }
            bottom--;
        }
        //traversing bottom to top if left not equal to right
        if(left<=right){
            for(int i=bottom;i>=top;--i){
                list.add(matrix[i][left]);
            }
            left++;
        }
      }
      return list;
    }
}
```
