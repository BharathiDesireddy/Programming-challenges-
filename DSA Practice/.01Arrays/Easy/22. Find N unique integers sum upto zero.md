# problem no : 1304
# problem : [Find N unique Integers sum upto zero](https://leetcode.com/problems/find-n-unique-integers-sum-up-to-zero/description/)
# Description :
Given an integer n, return any array containing n unique integers such that they add up to 0.

 

Example 1:

Input: n = 5

Output: [-7,-1,1,3,4]

Explanation: These arrays also are accepted [-5,-1,1,2,3] , [-3,-1,2,-2,4].

### Java Solution :
```java
class Solution {
    public int[] sumZero(int n) {
        int[] result = new int[n];
        for(int i=0;i<n-1;i+=2){
            result[i]=i+1;
            result[i+1]=-(i+1);
        }
        return result;
    }
}
